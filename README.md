# B2B Virtual CFO (VCFO) Lead Finder - India

An automated, public-signal B2B lead discovery platform designed for Virtual CFO service firms in India targeting mid-market companies (₹5 Cr - ₹50 Cr ARR | 20-250 Employees).

## Features
- **⚡ Automatic Lead Finder**: Single-click B2B lead research pipeline.
- **18-Column Master Data Schema**: Standardized lead research table format with verified public citations.
- **Deduplication Engine**: Excludes existing client domains and custom company lists.
- **Multi-Worksheet Excel Export**: Exports grouped Industry worksheets/tabs in a single Excel (`.xlsx`) file.
- **Clickable Hyperlinks**: Native click-to-open URLs for company websites, CEO LinkedIn profiles, and MCA/press sources.
- **Lead Scoring System**: Rule-based scoring (1-10) considering revenue, headcount, decision-maker presence, and dated 2024-2026 growth triggers.

## Tech Stack
- **Frontend**: React 18, Vite 6, Tailwind CSS, Lucide React
- **Export Engine**: SheetJS (`xlsx`)

## Quick Start

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build production bundle
npm run build
```
